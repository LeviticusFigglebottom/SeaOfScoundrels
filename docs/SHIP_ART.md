# Ship art: the sloop model contract

Generated by `tools/blender/gen_sloop.py` (run by `tools/build_assets.sh`) into `assets/generated/ship/sloop.glb` and
`sloop_lod.glb`. Checked by `tests/test_sloop_art.gd`; looked at with `scenes/showcase/shipart_showcase.tscn`.
Coordinates are ship-local: -Z bow, +Y up, +X starboard, origin at the waterline amidships.

## Materials (stable names, for shaders to target)
| Name | Used for | Notes |
|---|---|---|
| `mat_wood` | all timber | grain texture x vertex colour (paint colours are vertex colour too) |
| `mat_paint` | figurehead, carved sun, small painted parts | vertex colour only |
| `mat_rope` | all rope | |
| `mat_iron`, `mat_brass` | metal fittings | metallic |
| `mat_canvas`, `mat_canvas_back` | forward and aft face of the sail | back has the print ghosted and a little emission |
| `mat_cloth` | hammock, cushions, curtains, rug | two-sided |
| `mat_flag` | flag | two-sided |
| `mat_lantern_glass` | lantern panes, candle flame | emissive |
| `mat_window_glass` | stern windows | alpha blended, faint emission: raise `emission_energy_multiplier` at night |
| `mat_collision` | `col_*`, `mask_water` | hide these nodes |
| `mat_canvas_lod`, `mat_canvas_back_lod` | LOD sail | |

## Wind weights
`Sail` and `Flag` carry UV2: `UV2.x` is how much the vertex may move (sail: 0 at the yard and side bolt ropes, 1 in the belly,
about 0.65 along the foot; flag: 0 at the hoist to 1 at the fly), `UV2.y` runs 0..1 down the sail / down the hoist.
Vertex colour stays the albedo tint.

## Parts that move
| Node | Pivot | Motion |
|---|---|---|
| `Wheel` | hub | spin about local Z |
| `Rudder` | hinge line | yaw about Y |
| `Yard`, `Sail`, `Sail_Furled` | mast axis at the yard (0, 9, -1) | yaw together for trim, clear of the rigging over +-1.2 rad; show `Sail` or `Sail_Furled`; scaling `Sail` in Y also furls it |
| `Flag` | masthead | yaw to the apparent wind |
| `Capstan` | base centre | spin about Y |
| `Anchor` | ring | lower it; cable from `AnchorCablePoint` |
| `Cannon_Port`, `Cannon_Starboard` | carriage centre on deck, -Z = muzzle | yaw / recoil |
| `Cannon_*/Cannon_*_Barrel` | trunnion axis | pitch about local X |
| `HatchCover_Port`, `HatchCover_Starboard` | hinge on the coaming | shown open; rotate about Z by -102 / +102 degrees to close |
| `Bell` | hanging point | swing |
| `Rope_Sheet_*`, `Rope_Brace_*` | one end | unit rope along local +Z: each frame set origin to `SheetPoint_*` / `BracePoint_*`, aim +Z at `Sail/Clew_*` / `Yard/Yardarm_*`, Z scale = distance |
| `Lantern_Stern`, `_Mast`, `_Helm`, `_Hold`, `_Hold_Fore` | lamp centre | attach lights |

## Damage
Ten positions, `NN` = 01..10 (01-05 starboard, 06-10 port). Default: `HullPanel_NN` visible, `Hole_NN` and `HolePatch_NN` hidden.
Breach: hide `HullPanel_NN`, show `Hole_NN` (same planking with a real hole through it). Repair: also show `HolePatch_NN`.
All three share one origin, mid-planking at the hole centre, with -Z pointing outboard.

## Hide at load
`col_*` (convex collision pieces), `mask_water` (hull interior outline at y = 0, for cutting the sea out of the hold),
`Hole_*`, `HolePatch_*`, `Sail_Furled`.
