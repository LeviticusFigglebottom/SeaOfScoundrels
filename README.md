# Sea of Scoundrels

A stylized pirate sandbox for one captain and an AI crew, or friends in co-op. Built in Godot 4.7.2 with fully original, generated assets.

- Design: [docs/DESIGN.md](docs/DESIGN.md) · Roadmap: [docs/ROADMAP.md](docs/ROADMAP.md) · Architecture: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Decisions: [docs/DECISIONS.md](docs/DECISIONS.md) · Progress: [docs/PROGRESS.md](docs/PROGRESS.md)

```
tools/setup_env.sh        # install pinned Godot and Blender (Ubuntu)
godot --path .            # play
tools/test.sh             # headless tests
tools/build_assets.sh     # regenerate all assets
tools/capture.sh res://scenes/main.tscn demo 3 10   # off-screen frames and mp4
```
